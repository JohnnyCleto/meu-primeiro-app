# FoodGo

Aplicativo mobile de delivery de comida, inspirado no iFood, desenvolvido em React Native com Expo Router. Projeto acadêmico: um protótipo mockado (sem backend), focado no layout e no fluxo de navegação de um app real de pedidos.

## Telas

- **Login** — tela inicial de acesso
- **Home** — banner de ofertas em carrossel, categorias, mais pedidos e restaurantes perto de você
- **Busca** — pesquisa de restaurantes e pratos com filtro em tempo real
- **Restaurante** — página da loja com cardápio, destaques, categorias, avaliações e informações
- **Prato** — detalhes do item, ingredientes e botão de adicionar ao carrinho
- **Carrinho** — itens do pedido, resumo, cupom e finalização
- **Perfil** — dados do usuário, benefícios e opções de conta

## Tecnologias

- [Expo](https://expo.dev)
- [Expo Router](https://docs.expo.dev/router/introduction/) (navegação por arquivos)
- React Native

## Como rodar o projeto

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:

   ```bash
   npx expo start
   ```

3. Abra o app:
   - Escaneie o QR code com o app **Expo Go** (Android ou iOS), no mesmo Wi-Fi do computador; ou
   - Pressione `w` no terminal para abrir no navegador; ou
   - Pressione `i` ou `a` para abrir em um simulador iOS/Android, se instalado.
